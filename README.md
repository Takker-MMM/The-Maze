# The-Maze

壁を避けてスタートからゴールを目指す、ブラウザ向けの迷路ゲームです。

## 遊び方

`python3 server.py` を実行し、ブラウザで `http://127.0.0.1:8000/` を開くと遊べます。Codespacesや別の端末からアクセスする場合は、ポート `8000` を公開または転送して、そのURLを開いてください。`--host 0.0.0.0` がデフォルト値です。

「スタート」を押すと3秒のカウントダウン後に迷路が表示され、同時にタイマーが動き始めます。全5ステージの迷路は毎回ランダムな順番で登場し、5つすべてをクリアします。黄色い丸がプレイヤー、緑の枠と `START` の表示がスタート位置、赤い輪と `GOAL` の表示がゴール位置です。矢印キーまたは `W` `A` `S` `D` でプレイヤーを動かし、画面下部の矢印ボタンでも操作できます。壁には進めません。迷路をクリアするとタイマーが止まり、「次のステージに進む」ボタンが表示されます。

各迷路について、開始・移動ごとの座標（スタートを `(1, 1)`、ゴールを `(9, 9)` とする座標）・経過時間、ゴール時のタイム・クリアまでの移動回数をログに記録します。5つすべてをクリアすると、画面下部に「迷路1」から「迷路5」までのログが表示されます。

全ステージをクリアした後は、攻略した順番に各迷路のアンケートへ進みます。「面白さ」「難しさ」「ストレス」をそれぞれ5段階で評価し、すべての回答が終わるとプレイデータと「迷路Nの評価」を含むログが表示されます。

最後のアンケートでは、5つの迷路を参考にしながら具体的な感想を任意で自由記述できます。未記入の場合は「（記述なし）」としてログに記録されます。
